**SweaxClip 1.4.1**

- **One line of code is code.** Single lines such as `print("Merhaba Dünya!")`, `x = 5`, `import os`, `SELECT * FROM users`, `<div>…</div>` or `{"a": 1}` now land in Code, not only shell commands. Plain sentences stay text. Clips already in your archive are sorted again once (text → code only).
- **Clearer hover buttons.** Pin and delete now sit on a solid chip, readable over pictures and code.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.4.1` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.

---

**Türkçe:** Tek satırlık kod artık Kod kategorisine düşüyor: `print("Merhaba Dünya!")` gibi fonksiyon çağrıları, `x = 5` gibi atamalar, `import`/`def`/`#include` ile başlayan satırlar, SQL, HTML etiketi, JSON ve CSS. Düz cümleler metin olarak kalıyor. Arşivindeki eski kayıtlar bir kez yeni kurallarla yeniden ayrılıyor (yalnızca metin → kod). Kaydın üzerine gelince çıkan sabitle/sil düğmeleri artık dolu bir çipin üstünde; görsellerin ve kodun üstünde de net görünüyor.
