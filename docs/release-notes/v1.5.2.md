**SweaxClip 1.5.2 — macro keys**

- **Shortcuts from macro keys.** Keys sent by macro software and keyboard drivers used to be ignored, so a macro key that pressed the shortcut did nothing. They count now; only the keys SweaxClip sends itself are skipped.
- **Record the panel shortcut.** Settings → General → *Shortcut*: click it and press the keys, or press a macro key that sends a combination (it used to be a list of three choices). The same works for *Copy text from screen*.
- F13–F24, Pause, Scroll Lock and the launch keys can be a shortcut on their own. Macro apps that run programs can use `SweaxClip.exe --toggle` and `--grab`.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.5.2` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.
