**SweaxClip 1.5.5**

- **Browsing glides.** The list used to jump by a whole row at a time while you moved through it, which looked like a few frames a second. It now glides on a spring, keeps up with a held arrow key, and the mouse wheel glides too.
- **Drawn by the graphics card all the way.** The panel is no longer a layered window, whose every frame had to be copied back from the graphics card — slow at high refresh rates or with games, live wallpapers and overlays running.
- **Opens over Windows' own surfaces.** Task View, the notification centre and the snipping overlay are closed first, like Start and Search, and the panel is raised above any other always-on-top window that covers it.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.5.5`; checksums are in `SHA256SUMS.txt`.
