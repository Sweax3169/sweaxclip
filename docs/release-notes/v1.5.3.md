**SweaxClip 1.5.3**

- When a shortcut recorder gets a single ordinary key, the note now names it and says why it can't stand alone. A macro key with nothing recorded on it sends a plain key (F1 on many gaming keyboards); record a combination on it first, or a single Pause or Scroll Lock, which work alone.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.5.3`; checksums are in `SHA256SUMS.txt`.
