**SweaxClip 1.7.0 — Win+V that never waits**

- **No more half-minute waits.** The clipboard was read on the UI thread, and apps that make their copy only when it is read (Android Studio and other Java apps, Office, games) could keep it waiting up to 30 seconds — Win+V with it. The clipboard now has a thread of its own, and so does the panel: the keyboard hook talks to it directly, and nothing else in SweaxClip can hold it up.
- **Opens in 15–30 ms, even under load.** The rows are kept ready while the panel is hidden, SweaxClip runs above normal priority and stays in memory, so busy builds, renders and emulators don't slow it down.
- **Opens where you are.** Better caret finding in browsers and Electron apps; where there is no text cursor, the panel opens by the mouse pointer.

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.7.0`; checksums are in `SHA256SUMS.txt`.
