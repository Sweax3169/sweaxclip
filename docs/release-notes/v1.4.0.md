**SweaxClip 1.4** — make it yours.

- **Two panel styles.** Settings → Appearance: Timeline (default) or Deck, the spring-animated deck of cards, back as an option.
- **Theme:** follow Windows, or always light or dark.
- **Seven palettes** — Ember, Graphite, Midnight, Sage, Ocean, Rose, Mono — each in light and dark, applied instantly to the whole app.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.4.0` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.
