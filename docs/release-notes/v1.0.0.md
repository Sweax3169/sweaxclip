**SweaxClip 1.0** — a clipboard that never forgets.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Unzip, run `SweaxClip.exe`. Nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Run `SweaxClip.exe`, then press <kbd>Win</kbd> + <kbd>V</kbd>. It installs itself to `%LOCALAPPDATA%\Programs\SweaxClip` and starts with Windows. For a portable copy, create an empty `sweaxclip-data` folder next to the exe before the first start.

Windows SmartScreen may warn because the exe is not code-signed: *More info → Run anyway*. This release was built from tag `v1.0.0` by [`.github/workflows/build.yml`](https://github.com/Sweax3169/sweaxclip/blob/main/.github/workflows/build.yml); checksums are in `SHA256SUMS.txt`.

---

**Türkçe:** `SweaxClip-win-x64.zip` dosyasını indir, aç, `SweaxClip.exe`'yi çalıştır ve <kbd>Win</kbd> + <kbd>V</kbd>'ye bas. Kendini `%LOCALAPPDATA%\Programs\SweaxClip` klasörüne kurar ve Windows ile başlar. SmartScreen uyarı verirse: *Ek bilgi → Yine de çalıştır*.
