**SweaxClip 1.1** — redesigned to look and behave like part of Windows 11.

- Windows 11 design: Segoe UI, Fluent controls, Mica and Acrylic.
- Follows your light/dark theme and accent colour.
- The quick panel opens under the text cursor (including in Chrome and Edge) or above the taskbar, and slides in like a Windows flyout.
- Category tabs in the quick panel; hold Alt for 1–9 shortcuts.
- Library and settings laid out like Windows Settings.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating from 1.0: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history is kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.1.0` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.
