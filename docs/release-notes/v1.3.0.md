**SweaxClip 1.3** — a new Win + V panel.

- **A timeline you can read at a glance.** Every clip shows its content; the time it was copied runs down a rail. The selected clip opens on a spring: more text, a real image preview with the text read from it, more code, the full address of a link, and the app it came from.
- **Works over Start and Search.** If Start or Windows Search is open when you press the shortcut, SweaxClip closes it, opens above the taskbar and pastes your pick into Search.
- Search marks the matching words; the panel glides to the size of the results.
- Dark mode is dark all the way, including the library's cards.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history is kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.3.0` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.
