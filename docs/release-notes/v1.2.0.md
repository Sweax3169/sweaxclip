**SweaxClip 1.2** — a design of its own.

- **The deck:** <kbd>Win</kbd> + <kbd>V</kbd> deals your history as a deck of cards, exactly where Windows opens its own panel. Arrow keys flip through it; <kbd>Enter</kbd> throws the card at your text cursor.
- **Every clip is an object:** paper for text, the site's colour for links, slate for code, the colour itself, prints for images, a bezel with crop marks for screenshots, a manila folder for files.
- **The library is a desk:** click any card to pick it up and see it whole, with the text found in it.
- New palette, icons and app icon.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history is kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.2.0` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.

**Türkçe:** SweaxClip 1.2 artık kendi tasarımıyla geliyor. <kbd>Win</kbd> + <kbd>V</kbd> geçmişini Windows'un kendi panelini açtığı yerde bir kart destesi olarak dağıtır; oklarla çevirirsin, <kbd>Enter</kbd> kartı imlece fırlatır. Her kayıt kendi nesnesi olarak çizilir (kâğıt, arduvaz, renk, baskı, ekran çerçevesi, manila klasör); kütüphane bir masa, karta tıklayınca eline alırsın. Güncellemek için tepsi simgesinden çık ve yeni `SweaxClip.exe`'yi çalıştır; geçmişin korunur.
