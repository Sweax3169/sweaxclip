**SweaxClip 1.5.4**

- **Pastes where you are typing.** The panel no longer takes focus from the app below, so its text cursor stays put and the clip lands right there — in web forms, chat boxes and search fields too.
- **Opens at once, moves smoothly.** About 20–40 ms to open (it could take seconds) and the screen's full refresh rate while you browse.
- **Win+V answers every time.** The keyboard hook re-installs itself every 20 seconds and no longer waits behind memory clean-ups while you use the PC.
- Typing in the open panel goes to its search box (AltGr characters too); Alt+Tab and Alt+F4 still work; a click elsewhere closes it.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.5.4`; checksums are in `SHA256SUMS.txt`.
