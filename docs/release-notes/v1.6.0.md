**SweaxClip 1.6.0 — Win+V over administrator windows**

- **Work over administrator windows.** Windows keeps the keys typed into administrator windows (Task Manager, installers, an elevated terminal) away from ordinary apps, so Win+V there opened Windows' own panel. Turn on Settings → General → *Work over administrator windows*: SweaxClip then starts with administrator rights at sign-in. Windows asks for permission once.
- Links and files you open from SweaxClip still open as you, not as administrator, and the tray icon, `--toggle` and `--quit` keep working.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.6.0`; checksums are in `SHA256SUMS.txt`.

**Türkçe:** Windows, yönetici pencerelerine (Görev Yöneticisi, kurulum programları, yönetici komut istemi) basılan tuşları normal uygulamalara vermediği için Win+V orada Windows'un kendi panelini açıyordu. Ayarlar → Genel → *Yönetici pencerelerinde de çalış* açılınca SweaxClip oturum açışında yönetici yetkisiyle başlıyor; Windows yalnızca bir kez izin istiyor. SweaxClip'ten açtığın bağlantılar ve dosyalar yine senin adınla açılıyor; tepsi simgesi, `--toggle` ve `--quit` çalışmaya devam ediyor.
