**SweaxClip 1.5.1 — pasting works in every text box**

- **Notepad, Word and the rest.** Picking a clip pasted into browsers but not into apps whose text box is a separate control, such as Notepad. SweaxClip now waits until the text box you came from has focus again (and puts it back itself if the app doesn't) before it pastes. Text, images and files alike.
- **Text copied from the screen is kept.** Text read with <kbd>Win</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> now lands in your history too, labelled *Text from screen*.
- Ctrl+V is sent with real keyboard scan codes, and memory is handed back to Windows after a screen grab.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept.

SmartScreen may warn because the executable is not code-signed: *More info → Run anyway*. Built from tag `v1.5.1` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.

**Türkçe:** Yapıştırma artık her yazı kutusunda çalışıyor. Bir kayda basınca tarayıcılara yapışıyor ama Not Defteri gibi yazı kutusu ayrı bir parça olan programlara yapışmıyordu: Ctrl+V, program odağı yazı kutusuna geri vermeden geliyor ve kayboluyordu. SweaxClip artık paneli açtığın andaki yazı kutusunu hatırlıyor, odak oraya dönene kadar bekliyor (dönmezse kendisi geri veriyor), sonra yapıştırıyor; metin, görsel ve dosya için aynı. <kbd>Win</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> ile ekrandan kopyalanan yazı da artık geçmişe *Ekrandan metin* olarak düşüyor.
