**SweaxClip 1.0** — a clipboard that never forgets.

| File | For |
| --- | --- |
| `SweaxClip.exe` | Everyone. One file, nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |
| `SweaxClip-portable.zip` | Runs from a USB stick or any folder; the archive stays next to the exe. |

Run `SweaxClip.exe`, then press <kbd>Win</kbd> + <kbd>V</kbd>. It installs itself to `%LOCALAPPDATA%\Programs\SweaxClip` and starts with Windows.

Windows SmartScreen may warn because the exe is not code-signed: *More info → Run anyway*. This release was built from tag `v1.0.0` by the workflow in `.github/workflows/build.yml`; checksums are in `SHA256SUMS.txt`.

---

**Türkçe:** `SweaxClip.exe`'yi çalıştır ve <kbd>Win</kbd> + <kbd>V</kbd>'ye bas. Kendini `%LOCALAPPDATA%\Programs\SweaxClip` klasörüne kurar ve Windows ile başlar. SmartScreen uyarı verirse: *Ek bilgi → Yine de çalıştır*.
