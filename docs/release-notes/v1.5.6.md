**SweaxClip 1.5.6**

- **Deleting no longer throws you back to the top.** Scrolled down in the library or the panel, deleting a clip used to rebuild the list and jump to the first clip. The clip now folds away and everything else stays where it was — also when the library loads its next page, is resized, or something new is copied.
- **No more lurches while browsing big screenshots.** A screenshot full of text opened into a row taller than the panel and made the list leap when you moved on. The text read from a picture now shows three lines, and the list glides at a steady pace.

| File | For |
| --- | --- |
| **`SweaxClip-win-x64.zip`** | Everyone. Extract and run `SweaxClip.exe`; nothing else to install. |
| `SweaxClip-lite.exe` | PCs that already have the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0). Smaller download. |

Updating: quit SweaxClip from the tray icon, then run the new `SweaxClip.exe`. Your history and settings are kept. Built from tag `v1.5.6`; checksums are in `SHA256SUMS.txt`.
